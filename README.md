# 4DK4-Lab-1-2026

The purpose of this lab is to explore the performance of M/D/1 and M/M/1 queueing systems
through structured experimentation. You will investigate how delay, utilization, and queue length
behave under different traffic intensities. Particular emphasis is placed on understanding the im-
portance of the stability condition and observing how system behavior changes as traffic intensity
approaches and exceeds one.
